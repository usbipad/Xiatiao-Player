# Xiatiao Player 1.0.5

**发布日期**：2026-10-10

本次发布聚焦 **在线音源**、**沉浸式播放页** 与 **性能优化**。

---

## 新增

### 在线音源（Subsonic）

- 支持连接任意标准 Subsonic 服务端（如 Navidrome）：在线曲库浏览、搜索、播放、歌单、收藏。
- 音质档位选择与「实测音质」徽章。
- 在线音源默认关闭，需在设置中手动启用（保护隐私）。

### 多语言

- 界面支持中文 / English 切换，设置项、提示、后端消息均已翻译。
- 切换语言后可选择立即重启生效。

## 改进

### 沉浸式播放页

- 完整响应式布局，进入不再自动最大化。
- 前景色分区判定，歌词与频谱配色跟随背景明暗。

### 在线播放

- 修复进度回跳、切歌爆音等问题，播放更顺畅。
- 增强在线音源加载的健壮性。
- 修复搜索结果点歌时误从旧队列播放的问题。

### DLNA 投送

- 修复投送切音质时本机不播放、进度条状态同步等问题。

### 性能与界面

- 优化窗口最大化 / 切页的跟手度。
- 缓解切歌、开关页面时的内存增长。
- 设置页：外观页置首，分组归类更清晰。
- 可视化默认参数调整（更高帧率与更细腻的频谱）。
- 沉浸页背景模糊、进度条跟随封面、主页卡片轮播默认关闭。

### 系统托盘

- 修复托盘菜单点击无反应的问题。

---

## 安装

### Debian / Ubuntu

    sudo apt install ./xiatiao-player_1.0.5_amd64.deb

### Fedora

    sudo dnf install ./xiatiao-player-1.0.5-1.fcXX.x86_64.rpm

## 兼容性

- **deb**：Rust 后端最高只需 **GLIBC_2.34**，覆盖 Debian 12 / 13 / 14 与 Ubuntu 22.04 / 24.04 及更新。
- **rpm**：Fedora 专用。
