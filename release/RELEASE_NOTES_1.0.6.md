# Xiatiao Player 1.0.6

**发布日期**：2026-10-26

本次发布聚焦 **在线播放稳定性**、**音质识别准确性**、**Subsonic 适配器扩展** 与 **性能优化**。

---

## 新增

### 每日推荐

- 队列快播完时自动续拉下一批，长时间收听不重复。
- 实时流卡片常驻播放按钮，点击即播。

### 实验性：DSD 输出

- 新增 DSD 直通（Native / DoP）与转 PCM 软解，可在设置中选择模式与输出设备。
- **实验性功能**，仅在部分 ALSA 硬件验证，实际效果以本机为准。

### Subsonic 适配器扩展

- 适配器同步上线，推荐内容（排行榜 / 每日推荐 /
  猜你喜欢 / 私人电台 / 歌单分类）、扫码登录、用户资料与头像。
- 标准服务端（Navidrome / Airsonic 等）未实现这些端点时自动隐藏对应入口，
  不影响标准Subsonic服务的连接与播放。

## 改进

### 在线播放

- 在线流改用 Rust 原生解码，切歌与拖动进度条明显更快。
- 断流自动续传，不再因一次网络抖动跳到下一首。
- 断流重连不再空等，静音缝隙基本消除。
- 网络彻底不可用时按累计时长放弃并切歌，不再卡在原地。
- 曲目失效（404）立即跳过，不再等待超时。

### 音质识别

- 音质档位按歌曲实际可用规格动态显示，不再与实际码率错位。
- 修复在线流音质徽标（DXD）不显示的问题。
- 历史与收藏补存技术参数，重新载入后徽标不再丢失。

### DLNA 投送

- 修复 Range 请求返回数据过多的问题。

### 性能与界面

- 修复在线封面显示、页面记忆与列表显示的若干问题。
- 主界面修复空格键播放 / 暂停。

---

## 安装

### Debian / Ubuntu

    sudo apt install ./xiatiao-player_1.0.6_amd64.deb

### Fedora

    sudo dnf install ./xiatiao-player-1.0.6-1.fcXX.x86_64.rpm

## 兼容性

- **deb**：Rust 后端最高只需 **GLIBC_2.34**，覆盖 Debian 12 / 13 / 14 与 Ubuntu 22.04 / 24.04 及更新。
- **rpm**：Fedora 专用（需先启用 RPM Fusion 以获取完整 ffmpeg）。
- **DSD 输出**：实验性功能，需选择具体 ALSA 输出设备才能尝试直通。
