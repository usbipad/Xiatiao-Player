# Xiatiao Player 1.0.7

**发布日期**：2026-10-28

本次发布聚焦 **在线流缓存** 与 **播放稳定性**：缓存后的曲目重听完全不联网，
切歌与拖动进度条也更少受网络影响。

---

## 新增

### 在线流磁盘缓存

- 在线播放时把已下载的字节区间留在本地（`~/.cache/xiatiao/stream/`）。
- 再次播放同一首曲目时**完全不联网**，直接读本地文件。
- 往回拖动进度条到已下载区间零延迟，不再等 CDN 握手。
- 缓存按 LRU 淘汰，默认上限 2 GiB；可用环境变量
  `XIATIAO_STREAM_CACHE_MB` 调整（`0` 表示关闭）。

### 整曲主动预取

- 点播后后台把整首曲目拉到 EOF，**即使只听一半就切走**，
  这首也已完整落盘，下次可完整离线重听。
- 预取不限速，走独立连接，与解码连接由内核公平调度，
  不抢占「边播」所需带宽；预取到的区间解码线程直接命中，反而零网络。
- 切歌 / 播放结束时预取线程立即退出，不为已放弃的曲目占用带宽与磁盘。

## 修复

### 在线播放

- 服务端「接了连接却不下发数据」时不再无声卡死：读取超时后交由
  重试逻辑重连，可能命中新的节点。
- 修复缓存命中后网络流光标未跟进，把旧位置字节写到错误偏移、
  听感为「不同片段拼接」的问题。
- 拖动进度条后先静音并填够缓冲再出声，消除「磁带破损」般的断续杂音。

### 适配器

- 音频代理复用连接，减少每次 seek 的建连开销。

## 安装

本次起同时提供 **x86_64（amd64）** 与 **ARM64（arm64 / aarch64）** 两种架构的包。

### Debian / Ubuntu

    # x86_64
    sudo apt install ./xiatiao-player_1.0.7_amd64.deb
    # ARM64（树莓派 64 位系统、ARM 服务器、Asahi Linux 等）
    sudo apt install ./xiatiao-player_1.0.7_arm64.deb

### Fedora

    # x86_64
    sudo dnf install ./xiatiao-player-1.0.7-1.fcXX.x86_64.rpm
    # ARM64
    sudo dnf install ./xiatiao-player-1.0.7-1.fcXX.aarch64.rpm

## 兼容性

- **deb**：Rust 后端最高只需 **GLIBC_2.34**，同架构下覆盖
  Debian 12 / 13 / 14 与 Ubuntu 22.04 / 24.04 及更新。
- **rpm**：Fedora 专用（需先启用 RPM Fusion 以获取完整 ffmpeg）。
- **ARM 支持**：两种架构均由 GitHub Actions 在原生 runner 上构建
  （不做模拟），Debian 包统一在 Debian 12 基线上产出。
  暂不提供 32 位 armhf。
- **DSD 输出**：实验性功能，需选择具体 ALSA 输出设备才能尝试直通。
