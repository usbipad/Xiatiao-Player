# 代码审查 / 体检报告

本目录存放项目的「体检」记录：代码审查发现的问题、待办、已知缺陷与改进建议。

## 用途

- 记录每轮全项目或针对某模块的审查结果；
- 跟踪尚未处理的待办 / 遗留风险；
- 作为 `HANDOVER.md` 的补充——`HANDOVER.md` 描述「当前架构与现状」，
  本目录描述「发现了什么、还需要改什么」。

## 文件命名

`YYYY-MM-DD-<主题>.md`，例如：

- `2026-09-20-code-audit.md` —— 全项目代码审查
- `2026-09-20-ui-background.md` —— 某功能的专项审查

## 约定

- 每份报告按「模块」或「严重程度」组织；
- 已解决的问题标记 `✅`，并注明解决提交（短 hash）；
- 未解决 / 待确认的标记 `⬜`，写明原因与建议；
- 本目录仅为过程记录，不参与运行与打包。
